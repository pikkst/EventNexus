# Quick Start: Using Event Filters in Organizer Hub

## 🎯 How to Use the New Filtering Features

### Where to Find Filters
1. Log in to EventNexus as an organizer
2. Go to Dashboard (usually `/dashboard`)
3. Make sure you're on the **Insights** tab (default)
4. Scroll down to find **"Filter Your Events"** section
   - It appears right before the "Revenue by Event" table
   - Has a blue filter icon

### Filter Controls

#### 1. Search Box
- Type any part of your event name, location, or description
- Results update instantly as you type
- Example: Type "Summer" to find all events with "Summer" in the name

#### 2. Status Filter (Dropdown)
Choose what events to see:
- **All Status** - Show every event
- **Upcoming** - Only future events
- **Past** - Only completed events
- **Free** - Only free events (no ticket price)
- **Paid** - Only paid events

#### 3. Category Filter (Dropdown)
- Shows all categories from your events
- Only appears if you have events with categories
- Select a category to see only those events
- Example: Select "Tech" to see only tech events

#### 4. Sort/Order (Dropdown)
- **Date: Upcoming First** - Shows next events first (default)
- **Date: Recent First** - Shows most recent events first
- **Name: A-Z** - Alphabetical order by event name

### Filter Counter
Below the filter controls, you'll see:
- **"Showing X of Y events"**
- Shows how many events match your current filters

### Clear Filters Button
If any filters are active, a **"Clear Filters"** button appears:
- Click to reset all filters
- Shows all your events again

## 💡 Example Use Cases

### Find Your Next Event to Promote
1. Filter: Status = **Upcoming**
2. Sort: **Date: Upcoming First**
3. Your next event appears at the top of the list

### Find All Free Events
1. Filter: Status = **Free**
2. See all free events instantly
3. Useful for mass-updating or reviewing

### Search by Location
1. Type location name in Search box
2. Example: "Dublin" to find all Dublin events
3. Works with partial matches

### Find Events by Category
1. Use Category dropdown
2. Example: Select "Music"
3. See only music events

### Find Old Events
1. Filter: Status = **Past**
2. Sort: **Date: Recent First**
3. See recently completed events first

## 📊 Viewing Filtered Results

### Revenue Table Updates Automatically
- The Revenue by Event table below shows **only filtered events**
- Useful to see revenue for specific event types
- Example: Filter by "Paid" events to see paid ticket revenue

### Event Count Updates
- Counter shows filtered vs total events
- Example: "Showing 5 of 150 events (filtered)"

### Actions Still Work
- View, Edit, Delete buttons work on filtered events
- Payouts process for filtered events
- Archive/Delete works normally

## 🔧 Advanced Tips

### Combining Filters
You can use multiple filters together:
- Example: Show "Upcoming" + "Music" + "Dublin"
- See your upcoming music events in Dublin

### Search + Status Together
- Search: "Marathon"
- Status: "Upcoming"  
- Find upcoming marathon events only

### Filtering Large Event Lists
- With 600+ events, filtering is still instant
- No page refreshes needed
- Results update as you type

## ❓ Troubleshooting

### Filters Not Appearing?
- Make sure you have at least one event created
- Refresh the page (Ctrl+R or Cmd+R)
- Clear browser cache if needed

### "Showing 0 of X events"?
- Your filters don't match any events
- Try clearing filters to reset
- Check spelling if using search

### Wrong Events Showing?
- Check all active filters (they compound)
- Click "Clear Filters" and start fresh
- Try one filter at a time

### Revenue Table Not Filtering?
- Page might be loading
- Try refreshing
- Report to support if persists
