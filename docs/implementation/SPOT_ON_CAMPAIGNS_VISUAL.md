## 🔄 Campaign Types by Strategy

### ACQUISITION (New Users)
```
Goal: Bring new users to platform
Target: attendees or platform-growth
Features: Map search, easy booking, QR tickets
Message: "50 Events Near You - Find on Interactive Map"
```

### CREATOR_ACQUISITION (More Organizers)
```
Goal: Get more event creators
Target: creators
Features: Free listing, AI tools, Stripe payouts
Message: "Zero Fees, AI Creates Content, Keep 95%"
```

### RETENTION (Bring Users Back)
```
Goal: Re-engage inactive users
Target: retention
Features: New features, improvements, more events
Message: "Welcome Back - 20 New Events Added This Week"
```

### ENGAGEMENT (Increase Activity)
```
Goal: Get users more active
Target: attendees or creators
Features: Social features, notifications, recommendations
Message: "Follow Your Favorite Organizers - Never Miss Events"
```

### SEASONAL (Time-Sensitive)
```
Goal: Capitalize on season/holiday
Target: seasonal
Features: Seasonal events, limited-time
Message: "Summer Festival Season - 40 Events This Month"
```

## ✅ Quality Checklist: "Spot On" Campaign

A campaign is considered **"spot on"** if it meets ALL criteria:

### Content Quality
- [ ] Uses **real data** from database (event counts, categories, cities)
- [ ] References **specific platform features** (map search, QR tickets, AI tools)
- [ ] Addresses **audience pain points** (high fees, hard to find events)
- [ ] Offers **concrete solutions** (95% revenue, instant tickets)
- [ ] Uses **no fake statistics** (no "10k users" if we have 6)

### Targeting
- [ ] Speaks to **specific audience** (attendees OR creators OR agencies)
- [ ] Uses **appropriate tone** (fun for attendees, professional for creators)
- [ ] Highlights **relevant features** (map for attendees, AI tools for creators)
- [ ] Includes **action-oriented CTA** (See Events, Start Creating, Join Now)

### Technical Accuracy
- [ ] Mentions **web platform** (www.eventnexus.eu, NOT "download app")
- [ ] References **real technology** (Stripe Connect, PostGIS, React, AI)
- [ ] Shows **actual capabilities** (what the platform really does)
- [ ] Uses **accurate pricing** (Free, Pro €19, Premium €49)

### Visual Quality
- [ ] Prompt describes **EventNexus UI** (map interface, event cards, dashboard)
- [ ] Shows **web platform** (MacBook, browser, NOT phone app)
- [ ] Includes **brand elements** (indigo colors, modern aesthetic, logo)
- [ ] Features **specific content** (Music events, Tallinn location, etc.)
