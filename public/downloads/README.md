# EventNexus Mobile Apps - Download Info

## EventNexus Scanner (For Event Staff)

**Purpose:** Scan tickets at event entrances

### Android App
**File:** EventNexusScanner.apk  
**Version:** 1.0.0  
**Size:** ~15 MB  
**Min Android:** 8.0 (API 26)

#### Installation Instructions

1. **Download APK** from this link or scan QR code
2. **Enable Unknown Sources:**
   - Go to Settings > Security
   - Enable "Install from Unknown Sources"
   - Or allow installation from browser/file manager
3. **Install:**
   - Open Downloads folder
   - Tap APK file
   - Follow prompts
4. **Launch:**
   - Open EventNexus Scanner
   - Enter scanner code from organizer
   - Start scanning tickets!

#### Permissions

- **Camera:** Required for QR code scanning
- **Internet:** Required for ticket validation

#### Features

✅ Fast QR code detection  
✅ Real-time ticket validation  
✅ Scanner code authentication  
✅ Live scan statistics  
✅ Material Design 3 dark UI  
✅ Works on all Android devices

## EventNexus Live Map (For Event Attendees)

**Purpose:** Discover events, buy tickets, and manage your event experience

### Android App

**File:** EventNexusLiveMap.apk  
**Version:** 1.0.0  
**Size:** ~20 MB  
**Min Android:** 8.0 (API 26)

#### Installation Instructions

1. **Download APK** from this link or scan QR code
2. **Enable Unknown Sources:**
   - Go to Settings > Security
   - Enable "Install from Unknown Sources"
   - Or allow installation from browser/file manager
3. **Install:**
   - Open Downloads folder
   - Tap APK file
   - Follow prompts
4. **Launch:**
   - Open EventNexus Live Map
   - Browse events on interactive map
   - Filter by distance and category
   - Purchase tickets (sign in required)

#### Permissions

- **Location:** Required for finding events near you
- **Internet:** Required for loading events and purchasing tickets

#### Features

✅ Interactive map with event markers  
✅ Location-based search (1-200km radius)  
✅ Category filtering (Music, Sports, Arts, etc.)  
✅ In-app ticket viewing with QR codes  
✅ Secure authentication  
✅ Real-time event updates  
✅ Material Design 3 UI
